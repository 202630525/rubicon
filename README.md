# 🐟 Feed The Fish Game

A lightweight, interactive browser game built with HTML5 Canvas, CSS, and JavaScript. 

## 🎮 How to Play
1. Click inside the aquarium to drop food pellets for the fish.
2. Watch the fish automatically swim over to eat the food.
3. Keep an eye on the **Hunger Meter**—feed the fish regularly to keep it full!

## 🚀 How to Host on GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and create a new public repository named `feed-the-fish`.

2. **Upload Files**:
   - Add `index.html`, `style.css`, `script.js`, and `README.md` to your repository.

3. **Enable GitHub Pages**:
   - Go to your repository **Settings**.
   - Navigate to **Pages** in the left menu.
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Select the `main` branch (and `/root` folder), then click **Save**.

4. **Play Your Game**:
   - Wait 1-2 minutes for GitHub to build the page.
   - Access your live website at: `https://<your-username>.github.io/feed-the-fish/`
